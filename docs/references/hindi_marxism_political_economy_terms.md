# Hindi terminology: Marxism, political economy and general economics

Use this as a controlled reference during Hindi translation. Prefer the forms in the **Hindi term** column. Where an English phrase names a formal Marxist category, keep it in parentheses on first occurrence if the audience may need to verify the source term.

## Marxism, philosophy and historical materialism

| Hindi term | English concept | Usage note |
|---|---|---|
| मार्क्सवाद | Marxism | General name of the theory and tradition. |
| ऐतिहासिक भौतिकवाद | historical materialism | Do not dilute to “materialist history.” |
| द्वन्द्वात्मक भौतिकवाद | dialectical materialism | Formal philosophical term. |
| भौतिकवादी दृष्टिकोण | materialist approach | Use where the source is not naming the formal doctrine. |
| विचारधारा | ideology | Prefer over “विचारों का समूह.” |
| वैज्ञानिक समाजवाद | scientific socialism | Established Marxist term. |
| सामाजिक विकास | social development | Use in historical-materialist discussion. |
| सामाजिक ढाँचा | social structure | Use for a society’s structure; not necessarily “अधिरचना.” |
| आर्थिक आधार | economic base | Pair with “अधिरचना” in base-superstructure analysis. |
| अधिरचना | superstructure | Formal Marxist term; do not use “ऊपरी ढाँचा.” |
| अन्तर्विरोध | contradiction | Use in dialectical/class analysis; not “असहमति.” |
| सामाजिक अन्तर्विरोध | social contradiction | Use where class relations are the source of the contradiction. |
| ऐतिहासिक युग | historical epoch | Preferred for a distinct historical period. |
| सामाजिक संरचना | social formation / structure | Choose “सामाजिक संरचना” when the source emphasizes composition or arrangement. |

| सामूहिक स्वामित्व | collective ownership | Do not confuse with state ownership without context. |

|---|---|---|

| उत्पादक शक्तियाँ | productive forces | Formal historical-materialist category. |

## Editorial rules

1. Keep **मूल्य** and **कीमत** distinct.
2. Keep **अतिरिक्त मूल्य**, **मुनाफा**, and **मजदूरी** distinct.
3. Keep **श्रम** and **श्रम-शक्ति** distinct.
4. Keep **स्थिर पूँजी**, **स्थिर पूँजीगत साधन**, **परिवर्तनशील पूँजी**, and **परिचलनशील पूँजी** distinct.
5. Use **सर्वहारा वर्ग** and **बुर्जुआ वर्ग** for formal class categories; do not replace them with broad social labels.
6. Use **अन्तर्विरोध** for a dialectical or structural contradiction, not for a casual disagreement.
7. On first use of a specialised term, write: `preferred Hindi term (English source term)`; use Hindi alone after that.

## Source basis

This list uses the terminology visible in the supplied Hindi editions, especially forms such as **सर्वहारा वर्ग**, **बुर्जुआ वर्ग**, **वर्ग संघर्ष**, **उत्पादन प्रणाली**, **अतिरिक्त मूल्य**, **द्वन्द्वात्मक भौतिकवाद**, **वैज्ञानिक समाजवाद**, **अवसरवाद**, **राज्यसत्ता**, and **सर्वहारा अधिनायकत्व**. It is a translation-control reference, not a claim that every historic Hindi edition uses one identical spelling.
